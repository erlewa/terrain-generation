- **Compares different sediment transport equations under different hydraulic conditions**
- Formulas for sediment transport differ depending on whether the flow is laminar or turbulent
	- Should not use equations for turbulent stream when simulating erosion via overland flow
- Sheet flow is generally laminar, overland flow falls into this category
- Reynolds number is defined as the ratio between inertia and viscous forces
	- When Reynolds number is large flow is turbulent, when small flow is laminar

- Examines four types of overland flow:
	- Laminar sheet flow
	- Turbulent smooth flow
	- Turbulent rough flow
	- Turbulent rough flow with very small relative roughness
